# 🚀 Netlify Deployment Guide — TNAU Agri Portal

This folder is a standalone, production-ready bundle of the entire TNAU Agri Portal.

## ⚡ Option 1: Drag & Drop (Fastest)
1. Log into your account at https://app.netlify.com
2. Go to Sites.
3. Drag and drop this entire Hosting folder into the Netlify drop zone.
4. Your site will be live immediately with HTTPS and CDN acceleration!

## 📦 Package Contents
- All HTML pages with whole-card click navigation and pure CDN icons
- Complete 99 HD institution photos (img-cards/)
- Full 360 virtual campus tour (University-Tour/)
- Configured _redirects and netlify.toml for production routing and security headers
